# TAFHAHAS – AI-Powered DeepFake Voice Detection

An AI-powered system to detect AI-generated voice cloning (DeepFake audio) for enhancing security and preventing impersonation fraud.  
The project integrates **CNN**, **BiLSTM**, and a **Hybrid Model** with spectrogram-based analysis and data augmentation.  
Achieved **93.54% accuracy** on evaluation datasets.

---

## 📂 Repository Structure
- **TAFAHAS full pipeline.ipynb** → End-to-end notebook (data preprocessing, training, testing).  
- **TAFAHAS model only.ipynb** → Lightweight version focusing on the model code.  
- **mediaUI/** → Screenshots of the project’s user interface.  
- **TAFAHAS_demo_video.MP4** → Demo video walkthrough.  

---

## 🚀 Features
- Spectrogram-based DeepFake audio classification.  
- Combines CNN and BiLSTM for robust detection.  
- Data augmentation to handle class imbalance.  
- Interactive demo video and UI screenshots included.

- Accuracy: **93.54%**  
- Evaluation Metrics: Confusion matrix and performance charts (see `mediaUI`).
